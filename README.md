# 🚀 실시간 핫딜 알림 & 트렌드 지속 학습 봇 (`deal-bot`)

스레드 상위 1% 큐레이터 스타일로 **[트렌드 취미 연계 후킹 + 체감 단가 분석 + 100% 쿠팡 파트너스 단일 링크]** 3단 초압축 메시지를 생성하여 **스레드(Threads API)**와 **텔레그램(Telegram)**으로 무인 자동 발행하는 봇입니다.

또한, **시계열 머신러닝 시간 감쇄(Time-decay) 엔진**을 탑재하여 최신 유행어와 고반응 후킹을 매일 스스로 학습하고, **매일 밤 11시(KST 23:00)** 시스템 운영 보고서를 텔레그램으로 자동 브리핑합니다.

---

## 📱 핵심 기능 및 특징

1. **시계열 트렌드 지속 학습 (Continual Learning)**:
   * 매일 바이럴 계정 피드를 수집하여 `trend_timeline.jsonl`에 시간순 아카이빙
   * 머신러닝 시간 감쇄 공식($e^{-\lambda \Delta t}$, 반감기 14일)을 통해 최신 트렌드 가중치 산출
   * `dynamic_hook_pool.json`을 자동 갱신하고 가중치 기반 확률적 샘플링으로 카피 생성
2. **100% 쿠팡 파트너스 수익화 (`AF9052431`)**:
   * 비수익성(알뜰폰, 상품권 등) 딜 원천 필터링
   * 타사(11번가, G마켓 등) 핫딜도 쿠팡 최저가 검색 파트너스 링크로 강제 전환
3. **스레드(Threads) 도달률 최적화**:
   * 본문 후킹 + 첫 번째 댓글 링크의 **2단 분리 포스팅**으로 메타 알고리즘 페널티 완벽 우회
   * 10분 쿨다운 및 심야 수면 모드(01:00~07:00 KST)로 계정 보호
4. **일일 정기 보고서 발송 (Daily Reporter)**:
   * 매일 밤 11시(KST 23:00) 일일 트렌드 학습 현황 및 핫딜 발송 통계를 텔레그램으로 자동 보고
5. **GitHub Actions 완전 무인 클라우드 운영**:
   * 피크타임(08:00~24:00 KST) 20분마다 핫딜 감시 및 발송
   * 매일 오전 9시 트렌드 수집 & 지속 학습 자동 실행

## 📁 주요 파일 구조

* `trend_analyzer.py`: 머신러닝 시간 감쇄 가중치 공식 및 급상승 키워드 추출기
* `dynamic_hook_pool.json`: 시간 감쇄 점수가 반영된 카테고리별 동적 후킹 풀
* `trend_timeline.jsonl`: 시간 순서대로 누적되는 시계열 트렌드 데이터베이스
* `harvest_threads.py`: 스레드 벤치마킹 계정 시계열 데이터 수집기
* `daily_reporter.py`: 매일 밤 11시 텔레그램 일일 보고서 생성 및 발송 모듈
* `copywriter.py`: 동적 후킹 풀 기반 가중치 확률 샘플링 카피 생성기
* `link_helper.py`: 100% 쿠팡 파트너스 링크 전환 엔진
* `scraper.py`: 뽐뿌 핫딜 및 원문 맥락/고해상도 이미지 크롤러
* `threads_poster.py`: 메타 공식 Threads Graph API 연동기
* `notifier.py`: 텔레그램 알림 발송 모듈
* `main.py`: 전체 핫딜 모니터링 & 발송 파이프라인
* `.github/workflows/`:
  * `deal_bot.yml`: 20분 주기 핫딜 감시 및 무인 발송
  * `harvest.yml`: 매일 오전 9시 트렌드 시계열 수집 및 머신러닝 학습
  * `daily_report.yml`: 매일 밤 11시(KST 23:00) 텔레그램 일일 리포트 자동 발송

## ⚡ 실행 방법

* **24시간 자동 모니터링:** `run.bat` 더블 클릭
* **최신 핫딜 1건 테스트 발송:** `python main.py --test`
* **일일 리포트 즉시 발송 테스트:** `python daily_reporter.py`
* **트렌드 학습 즉시 재실행:** `python trend_analyzer.py`
