# 🚀 실시간 핫딜 알림 봇 (`deal-bot`)

쓰레드 상위 1% 큐레이터 스타일로 **[후킹성 원글 + 가격 비교/단위 단가 + 단일 제품 링크]** 3단 구조의 고전환 메시지를 자동 생성하여 텔레그램으로 전송하는 봇입니다.

---

## 📱 발송 메시지 구조 (3단 미니멀 포맷)

1. **후킹성 원글**: 품목 카테고리(식품, 생필품, 전자기기 등)에 맞춘 자연스럽고 설득력 있는 1~2줄 카피라이팅
2. **가격 정보**: 정상가 앵커링 + 할인가(할인율) + **개당/봉당/g당 체감 단가 자동 계산**
3. **제품 링크**: 잡다한 버튼을 모두 없앤 단일 제품 바로가기 링크

---

## 📁 폴더 및 파일 구조

* `copywriter.py`: 후킹 멘트 생성, 가격/수량 추출 및 단위당 단가(체감가) 자동 계산
* `config.py`: 텔레그램 토큰, Chat ID, 쿠팡 파트너스 ID(`AF9052431`), 주기 설정
* `scraper.py`: 뽐뿌 핫딜 목록 크롤링 및 실제 쇼핑몰 원문 링크 디코딩
* `link_helper.py`: 상품명 정제 및 최적의 제품 구매 링크 생성
* `notifier.py`: 사진 및 3단 본문 전송
* `history.py`: 중복 알림 방지를 위한 `sent_deals.json` 관리
* `main.py`: 전체 파이프라인 제어 및 주기적 반복 실행기
* `run.bat`: 윈도우 더블 클릭 1회로 24시간 가동

---

## ⚡ 실행 방법

* **24시간 자동 모니터링 (추천):** `run.bat` 더블 클릭
* **최신 핫딜 1건 테스트 발송:** `python main.py --test`
* **1회 점검 후 종료:** `python main.py --once`
